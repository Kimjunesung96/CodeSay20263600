## 설치 방법 (Windows / PowerShell)

```powershell
git clone <repo주소>
cd ai_mobility_project

python -m venv .venv
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

### PowerShell 스크립트 실행이 막혀있을 때

`.\.venv\Scripts\Activate.ps1` 실행 시 아래 에러가 뜨면:

```
이 시스템에서 스크립트를 실행할 수 없으므로...
```

아래 명령을 한 번만 먼저 실행(관리자 권한 불필요, 현재 세션에만 적용):

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

그 다음 다시 `.\.venv\Scripts\Activate.ps1`을 실행하면 됨. 성공하면 프롬프트 앞에 `(.venv)`가 표시됨.

### SUMO 설치 (필수, 별도 프로그램)

`pip install`은 파이썬 라이브러리만 설치하며, SUMO 시뮬레이터 본체는 따로 설치해야 함:

1. https://sumo.dlr.de/docs/Downloads.php 에서 Windows용 설치 파일 다운로드
2. 설치 후 `SUMO_HOME` 환경변수가 잡혀 있는지 확인 (설치 프로그램이 보통 자동으로 설정함)
